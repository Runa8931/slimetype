# スライムタイピング

タイピングでスライムを育てて、モンスターとたたかうブラウザゲームです。
インストール不要。`index.html` をブラウザ(Chrome 推奨)で開くだけで遊べます。
※ 入力は「半角英数」モードで行ってください。

## 遊び方
1. **キャラ選択** — 3 種類のスライムから 1 体えらぶ(レベルはキャラごとに別々に保存)
2. **れんしゅう** — 制限時間内にお題を打つ。正しく・速く打つほど経験値が増える
3. **バトル (ワールドマップ)** — `WASD` でマップの道を走ってステージへ移動し、`Space` でバトル開始
   - ワールドは そうげん → うみ → ゆきやま → マグマのしろ の 4 つ (全 18 ステージ)
   - 敵をたおすと次のステージへの道がひらける。ボスをたおすと次のワールドへのゲートがひらく
   - `Tab` で横からステージ一覧を出して、直接えらぶこともできる
   - バトルではお題を打ち切るとスライムが攻撃。敵は攻撃ゲージがたまると攻撃してくる
   - コンボが続くほどダメージアップ(最大 1.5 倍)
   - 正しく打つと必殺技ゲージがたまり、満タンになると自動で発動
   - `Esc` でポーズ
4. **サバイバル** — `WASD` で動いて、まわりから迫ってくる敵の大群をしのぐアクションモード
   - 難易度: かんたん (ボス ドラゴン) / ふつう (クラーケン) / むずかしい (イエティ) / おに (まおう)
   - 攻撃は自動。敵が落とす 🎁 宝箱で武器を手に入れたり強化したりできる (3 つから 1 つえらぶ・最大 6 こ)
   - 武器 10 種: みずでっぽう / サンダー / いわシールド / ほのおのわ / ブーメラン / ホーミングスター / アイスノヴァ / レーザー / メテオ / たつまき (それぞれ Lv.5 まで)
   - 2:30 にボスが登場。たおせばクリア。ジェムと生きのこった時間 × 難易度の倍率が経験値になる
   - タイピングでレベルを上げるほど HP と攻撃力が上がって有利になる

## キャラクター
| スライム | 型 | とくせい | ひっさつわざ |
|---|---|---|---|
| ぷるん (みず) | バランス | ノーミスで打ち切ると HP 4% 回復 | アクアヒール: HP 40% 回復・どく解除・次の攻撃 1.5 倍 |
| ぴりり (でんき) | スピード | 速く打つほど会心率アップ | サンダーボルト: 威力 280 の大ダメージ |
| ごつん (いわ) | ぼうぎょ | 被ダメージ 20% カット・ミスしてもコンボ半分残る | ロックシールド: 2 回ガード+反撃 |

Lv.10 と Lv.20 で進化し、名前・体の色・形・かざりが変わります。

## 参考にした計算式
- **スコア**: e-typing の「WPM × 正確率³」(ここでは WPM = 1 分あたりの打鍵数)
- **必要経験値**: ポケモンの「中速グループ」(Lv³)を 0.8 倍
- **能力値**: ポケモンの能力値の式を簡略化 (HP = 2×種族値×Lv/100 + Lv + 10、その他 = 2×種族値×Lv/100 + 5)
- **ダメージ**: ポケモンのダメージ式 ((2×Lv/5+2) × 威力 × 攻撃/防御) / 50 + 2。威力は打ったキー数で決まる
- **バトルの勝利経験値**: ポケモン(第 1〜4 世代)の「基礎経験値 × 敵 Lv / 7」
- **れんしゅうの経験値**: 正しい打鍵数 × 正確率² × (1 + 打鍵/分 ÷ 300) × 難易度倍率

## ファイル構成
```
index.html        画面のひな形
css/style.css     見た目・アニメーション
js/romaji.js      ローマ字入力判定 (shi/si、っ、ん などの表記ゆれに対応)
js/words.js       お題リスト (日本語・英語)
js/data.js        キャラ・敵・成長の計算式
js/sprites.js     キャラ・敵の絵 (SVG)
js/effects.js     パーティクル・ダメージ数字・カットイン
js/audio.js       効果音 (ブラウザの音源機能で合成)
js/main.js        セーブ・画面切り替え・ホーム・キャラ選択・ステージ選択
js/practice.js    れんしゅうモード
js/map.js         ワールドマップ (バトルの入り口)
js/battle.js      バトルモード
js/survival.js    サバイバルモード
js/result.js      結果画面 (経験値・レベルアップ・進化演出)
```

セーブデータはブラウザ内 (localStorage) に保存されます。
