# スライムタイピング

タイピングでスライムを育てて、モンスターとたたかうブラウザゲームです。
インストール不要。`index.html` をブラウザ(Chrome 推奨)で開くだけで遊べます。
※ 入力は「半角英数」モードで行ってください。

## 遊び方
1. **キャラ選択** — さいしょは ぷるん。ほかの スライムは ぼうけんのとびらで ひらく(レベルはキャラごとに別々に保存)。ガチャ限定の 2 体は ガチャで 出ると えらべる
2. **れんしゅう** — 制限時間内にお題を打つ。正しく・速く打つほど経験値が増える
   - 「にがてキー特訓」: きろくした にがてなキーを たくさん使う お題だけが出る
3. **バトル (ワールドマップ)** — `WASD` でマップの道を走ってステージへ移動し、`Space` でバトル開始
   - 全 13 ワールド × 6 ステージ = 78 ステージ (各ワールドの 6 体目がボス) + **かくしステージ 2 つ**
   - かくしステージ: メインの ステージで 何かを たっせいすると マップに 道が ひらく。たおすと キャラが なかまに なる
     - どくぬまの ステージを 3 つ ノーミスで クリア → 「おうごんゴーレム」(たおすと ゴルりん)
     - ゆきやまの ボス イエティを 上級者で たおす → 「こおりの じょおう」(たおすと ゆきだるん)
   - そうげん → どくぬま → さばく → うみ → おかしのくに → あめのもり → きかいのこうじょう → ゆきやま → てんくう → うちゅう → マグマのしろ
     → **うらの せかい**: かげのもり (Lv101〜110) → ほしのはて (Lv110〜120、さいごは しんまおう)。敵と 同じ レベルなら ふつうの 敵に 7〜8 わり 勝てる 強さ
   - うらの せかいの 敵は「へんい種」。今ある 敵の 絵に 色の フィルターを かけて つかい回すので 重くならない。能力を 2〜3 こ 組み合わせて いる
   - 敵をたおすと次のステージへの道がひらける。ボスをたおすと次のワールドへのゲートがひらく
   - `Tab` で横からステージ一覧を出して、直接えらぶこともできる
   - **難易度**: マップや バトル前の 画面で `1` `2` `3` で えらぶ
     - どの 難易度でも 推奨レベル (= 敵の レベル) は おなじ。かわるのは 必要な タイピングの 速さだけ
     - 初心者: 1 分 100 打鍵 向け (敵の 強さ ×0.5) / 中級者: 200 打鍵 向け (×0.9) / 上級者: 350 打鍵 向け (×1.32 から はじまり、すすむほど 上がって さいごは ×1.65)
     - 推奨レベルで むいている 速さなら: 1-1 は Lv1 でも かてる・序盤は ふつうの 敵に 約 9 わり・終盤は 初心者/中級者 約 8 わり、上級者 約 5 わり (ぎりぎり)
     - さいごの しんまおうは Lv124 (Lv最大 + かくせい★4)
     - コインは 中級者 ×1.3・上級者 ×2 (経験値は どの 難易度でも おなじ)。クリアした 難易度は ステージに「初・中・上」の しるしで のこる
   - バトルではお題を打ち切るとスライムが攻撃。敵は攻撃ゲージがたまると攻撃してくる
   - コンボが続くほどダメージアップ(最大 1.5 倍)
   - 正しく打つと必殺技ゲージがたまり、満タンになると自動で発動
   - `Esc` でポーズ
4. **サバイバル** — `WASD` で動いて、まわりから迫ってくる敵の大群をしのぐアクションモード
   - 難易度: かんたん (ボス ドラゴン) / ふつう (クラーケン) / むずかしい (イエティ) / おに (まおう) / **じごく** (しんまおう・Lv110〜)
   - じごく: 「おに」を Lv70 で あそぶ 手ごたえを、Lv124・かくせい★4 で さらに 1.4 倍 きびしく したもの。うらの せかいの へんい種が 出る
   - 攻撃は自動。敵が落とす 🎁 宝箱で武器を手に入れたり強化したりできる (3 つから 1 つえらぶ・最大 6 こ)
   - 武器 19 種 (ソニックウェーブ・つきのや・どくのぬま・こばんなげ・ゆきだま・ゆうしゃのけん を 追加): みずでっぽう / サンダー / いわシールド / ほのおのわ / ブーメラン / ホーミングスター / アイスノヴァ / レーザー / メテオ / たつまき / つららのあめ / かまいたち / ドリル (それぞれ Lv.5 まで)
   - 2:30 にボスが登場。たおせばクリア。経験値は 1 レベルぶんが もとで、生きのこった 時間と 難易度で ふえる
   - タイピングでレベルを上げるほど HP と攻撃力が上がって有利になる
5. **モンスターずかん** — バトルで であった・たおした敵が登録される (78 + かくし 2 しゅるい)。たおした回数と さいそく撃破タイムも見られる
6. **しょうごう** — 「ノーミス勝利」「打鍵/分 250」など 78 こ (★ むずかしい しょうごう 10 こ ふくむ)。とった しょうごうは ホームに かざれる。1 つ とるごとに 100 コイン
7. **ガチャ** — コインで引く (1 回 100 / 10 回 1000 で SR 以上 1 つ かくてい)。さいしょに 1000 コイン プレゼント
   - 出るもの: キャラ・色ちがい (18)・ぼうし (18)・エフェクト (15)・**おとも** (8: スライムの そばに いる 小さな なかま)
   - 確率: ガチャ限定キャラ 6% (6 たい) / いつものキャラ 14% / アイテム 80% (SSR 3%・SR 12%・R 33%・N 52% の わりあい)。
     ガチャ画面の「📊 はいしゅつ かくりつ」(ラインナップ) で レア度 × しゅるいの 表と、1 つずつの 確率が 見られる
   - キャラが かぶると **せんざいかくせい** ★1〜★4: 能力値 +2%・レベルの上限 +1・キャラごとの とくせいが 少し のびる (★ ごとに)。
     足もとが 光り、★4 で 専用の いろ と しょうごう
   - ★4 の あとや、アイテムが かぶると **かけら 💎**。こうかんじょで キャラ (かくせい) や まだ もっていない アイテムと こうかん
   - コインの もらいかた: れんしゅう (打鍵 ÷ 8 × 正確率² × 難易度) / バトル (勝利 30 + ステージ番号 × 2。格下では へる。はじめて たおすと +50、ボスは +200) /
     サバイバル ((たおした数 ÷ 4 + 秒 ÷ 2 + クリア 150) × 難易度)
8. **きせかえ** — ガチャで てにいれた いろ・ぼうし・エフェクト・おともを キャラごとに つけかえる。エフェクトは バトルの 攻撃の 弾と、お題を 打ちおわったときに タイピングの 枠の まわりから 出る
10. **プレイ時間** — ホームの きろくに 表示。しょうごうの 画面で くわしい 内わけ (プレイ時間 / 裏画面 / モードごと)
   - 画面が 見えている 時間が プレイ時間、ほかの タブや アプリに かえている 時間が 裏画面
   - 「見えた・かくれた・画面を かえた」ときの 時刻の 差を 足すだけなので かるい (30 秒ごとに セーブ)
   - 記録を はじめる 前の セーブは、正しく 打った キーの 数から おおよその 時間を 出す (推定)
9. **ぼうけんのとびら** — ステージを すすめると あたらしい モードや スライムが つかえるように なる。開放の 条件を ならべた 画面
   - さいしょは ぷるん・れんしゅう・バトル・ずかん・しょうごう だけ
   - ワールド 1 の ボス → サバイバル・ぴりり / ワールド 2 → ガチャ・きせかえ / ワールド 3〜6 → ごつん・ほむら・もりりん・かげまる
   - れんしゅう 3 回 → にがてキー特訓 / サバイバルの 難易度は ひとつ 前を クリアすると ひらく
   - しょうごう「はやうち名人」→ おんぷる / 「かんぺき主義」→ ぴたりん / かくしステージ → ゴルりん・ゆきだるん
   - ミッション: ★ むずかしい しょうごう 3 こ → ゆうしゃりん / しょうごう 40 こ (★ 5 こ ふくむ) → おとも「ふしちょう」
   - 前の 版から あそんでいる セーブは、もう つかったことの ある ものは ひらいた 状態から はじまる

## キャラクター
キャラ選択・ホームで、とくせい・ひっさつ・サバイバルでの 強さを「ふつうの キャラは いくつで、どこまで 上がるか」の 数字つきで 見られます。
最大レベルは **Lv120** (かくせい ★ 1 つごとに +1)。**Lv20・40・60・80** で進化し (全 5 段階)、名前・見た目・とくせい・ひっさつが強くなります。
(Lv60 で つばさ、Lv80 で 光の輪が つきます)

## 敵の特殊能力 (おもなもの)
どく・やけど / ガイドを隠す (きり・すみ・かげろう・やみ) / げきど (HP 半分で速くなる) / よろい (コンボ 30 未満だとダメージ半減) /
からにこもる / しびれ (ミスで自分にダメージ) / 回復 / こごえ (しばらく 攻撃が 3 わり 弱くなる) / ふぶき・すなあらし (漢字とかなが見えない) /
**ぬかるみ** (攻撃でガイドが泥で見えにくくなる) / **あまいゆうわく** (ミスすると敵が回復) / **ためこうげき** (3 回に 1 回 強い攻撃) /
**かみなりのよこく** (3 秒以内にお題を打ち切らないと落雷) / **かぜ** (文字がゆれる) / **みつくび** (ヒュドラ: HP がへるほど攻撃回数がふえる)

各敵の強さは「敵と同じレベル・1 分 220 打鍵」で、ふつうの敵は勝率 8〜9 わり、ボスは 6〜7 わり になるよう計算で決めています。

## 参考にした計算式
- **スコア**: e-typing の「WPM × 正確率³」(ここでは WPM = 1 分あたりの打鍵数)
- **必要経験値**: ポケモンの「中速グループ」(Lv³)を 0.5 倍 (Lv120 まで)
- **能力値**: ポケモンの能力値の式を簡略化 (HP = 2×種族値×Lv/100 + Lv + 10、その他 = 2×種族値×Lv/100 + 5)
- **ダメージ**: ポケモンのダメージ式 ((2×Lv/5+2) × 威力 × 攻撃/防御) / 50 + 2。威力は打ったキー数で決まる
- **バトルの経験値**: 勝つと「その ステージの レベルから つぎの ステージの レベルまで」の 6 わり + 打鍵ぶん。推奨レベルで 勝ちすすむと つぎの 推奨レベルの すこし 手前に なる
- **れんしゅうの経験値**: 1 レベルぶん × (正しい打鍵数 × 正確率² × (1 + 打鍵/分 ÷ 300) ÷ 600) × 難易度倍率 (60 秒・200 打鍵で 約 0.5 レベル)
- **サバイバルの経験値**: 1 レベルぶん × 0.6 × 難易度 × 生きのこった 時間 (クリアで 1.5 倍)

## パソコンが熱くなるときは
ホーム画面右上の「✨ エフェクト」を **ひかえめ** にすると、動きのかざり・つぶの数・画面の細かさをおさえて軽くなります。
(サバイバルでは 敵の最大数も 90 体 → 60 体に減ります)
